05 / TRANSLATION · 完整讲法

同一份设计，我按听众换讲法。

设计做得再准，讲不清就等于没做。我给每个项目准备两条读法：对专业听众讲证据链与方法，对业主讲价值与体验。下面两条车道用的是同一批项目，只是入口不同。

车道 A · 评审 / 同行 / 技术负责人

已成册
他们要先确认
判断依据在哪，方法能不能迁移。
我的讲法
按证据链讲——从业主给的原始资料，一路推到能量出来的空间动作，每一步都能翻回上一页复核。
用哪个项目
适老化住宅改造《勿忘我》｜全国适老化设计竞赛 · 铜奖｜16 页册。打开 16 页阅读版（手机直接看，不用下载）↗
  1. 01P2–P3项目与用户竞赛档案 + 一份功能量表、两种生活状态
  2. 02P4–P6需求推导24 小时动线 → 九处空间问题 → 七空间需求矩阵
  3. 03P7–P15概念与方案三条策略、记忆宫殿、可量尺寸、辅具选型、三张展板
  4. 04P16复盘做对的、不足的、带走的

读完能回答：这个方案为什么必须是这样，换一块场地还成不成立。

车道 B · 业主 / 甲方 / 不学建筑的人

进行中
他们要先确认
这栋楼对我有什么用，我能不能看懂。
我的讲法
按价值讲——用业主自己的问题开场，先给三个记得住的回答，再让图和空间自己说话，术语留在附录。
用哪个项目
高层综合体设计｜课程项目｜14 页展板。业主版重排进行中，完成后在此上线（现在不给假链接）。
  1. 01P02一个问题开场就是业主原话：「高层办公建筑的价值？」
  2. 02P03三个回答企业形象 / 办公效率 / 长期价值，收口一句「我的方案正是围绕这三点展开」
  3. 03P05看得见的证据北立面 + 东南立面并置，把「价值」落到看得见的立面上
  4. 04P13只留必要的附录风热环境单页，标注「团队专题」，写清哪部分是团队协作

读完能回答：这栋楼对我值不值，以及其中哪些是我做的。

三条翻译规则（两条车道共用）

01 标题就是结论

页面标题写成完整判断句，不写标签。翻到任何一页，看第一行就知道这页在论证什么。

例：「九处空间问题：每一处都对应一个身体动作」「平面与尺寸：每个数字都能量出来」

02 每个数字都有出处

图和表旁边跟一行来源注，专业听众要复核时不用先来问我。

例：「主办方原始平面提供」「无障碍人体尺度规范」「2023 年辅具选择资料」

03 专业词换回生活词

概念页的名字本身就是「把认知干预翻译成空间语言」；对业主则直接用他的原话提问开场。

例：策略写「记忆站」、概念写「记忆宫殿」，而不是只丢一个术语
